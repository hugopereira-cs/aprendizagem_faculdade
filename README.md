# 📚 Projetos, Exemplos e Atividades da Faculdade

Este repositório reúne projetos, exemplos práticos e atividades propostas ao longo da graduação,
com foco no desenvolvimento de habilidades em diferentes áreas da computação.

---

## 🌐 Desenvolvimento Web

Projetos e atividades da disciplina de Desenvolvimento Web, abordando os seguintes tópicos:

- HTML
- CSS
- JavaScript
- PHP
- Banco de Dados

---

## 🐍 Python

Atividades e exemplos voltados para a compreensão dos conceitos fundamentais da linguagem Python, incluindo:

- Sintaxe básica
- Lógica de programação
- Programação Orientada a Objetos (POO)

---

## 🧱 Estruturas de Dados em C

Materiais desenvolvidos para fortalecer o entendimento das principais estruturas de dados em C, tais como:

- Filas (Queue)
- Pilhas (Stack)
- Listas
- Árvores
- Grafos
- Tabelas Hash

---

## ⚡ RAD com Python

Projetos, exemplos e atividades baseados no conceito de **Desenvolvimento Rápido de Aplicações**
(*Rapid Application Development – RAD*), utilizando a linguagem Python.
